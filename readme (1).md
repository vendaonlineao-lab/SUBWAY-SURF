# Subway Premiado - Arquivos para Hospedagem

Esta pasta contém apenas os arquivos leves e essenciais para hospedar o site no Netlify, Vercel ou qualquer hospedagem.

## 📁 Arquivos
- **index.html**: Página principal completa (HTML, CSS e JS otimizados com Panda Video e Utmify UTMs).
- **assets_surfe/**: Imagens e logos (fundo, favicon, logos Multicaixa e BNA).
- **favicon.ico / favicon.png**: Ícones do site.
- **_redirects**: Configuração para Netlify e Cloudflare Pages.
- **vercel.json**: Configuração para Vercel.
- **server.py**: Servidor local Python para testar no computador (`python3 server.py`).

## 🚀 Como Hospedar no Netlify
1. Acesse https://app.netlify.com
2. Vá na aba **Deploys**
3. Arraste esta pasta **SUBWAY SURFERS** inteira para a área de upload.
